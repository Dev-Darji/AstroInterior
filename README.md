# Self × Space × Design — Astrology, Vastu, Numerology & Interior Website

## 1. Project Overview

A premium, interactive Indian lifestyle and consultation website combining:

- 🔮 Astrology
- 🔢 Numerology
- 🧭 Vastu
- 🏠 Interior Design
- 🎨 Vastu × Interior Design
- 📅 Consultation & Lead Generation
- 📚 Insights / Blog

The core brand idea is:

> **SELF × SPACE × DESIGN**

- **SELF** → Astrology + Numerology
- **SPACE** → Vastu
- **DESIGN** → Interior Design
- **CONNECTION** → Vastu-aware Interior Design

### Core Brand Message

> **Where Energy Meets Design**

Supporting idea:

> Understand yourself. Understand your space. Design a place that feels right.

This is **not** intended to look like a generic astrology website. It should feel like a premium interior/design studio combined with a sophisticated Indian spiritual-guidance brand.

---

# 2. Project Goals

The website should:

1. Build trust.
2. Showcase premium interior projects.
3. Explain Astrology, Numerology and Vastu services.
4. Demonstrate the Vastu × Interior concept.
5. Generate consultation enquiries.
6. Make WhatsApp and contact actions extremely easy.
7. Provide useful interactive experiences.
8. Be responsive and fast.
9. Be SEO-ready.
10. Be structured for future backend/API/database integration.

# 63. Design Quality Bar

The website should look like a premium agency/client project.

Avoid:

- Template-like sections
- Excessive cards
- Repetitive 3-column grids
- Excessive gradients
- Excessive rounded corners
- Huge shadows
- Emoji-heavy UI
- Random icons
- Generic illustrations
- Excessive glassmorphism
- Overuse of gold

Prefer:

- Large editorial typography
- Whitespace
- Asymmetrical layouts
- Full-width imagery
- Subtle borders
- Natural textures
- Strong photography
- Architectural composition
- Restrained animation
- Sophisticated spacing
